PURPOSE AND FUNCTION
--------------------
AI Smartclass is a native Android classroom app with student, teacher, and
administrator portals. Teachers create digital MCQ and written-answer tests;
students answer in the app and submit JSON. The backend stores per-test AI
analysis and dated cumulative rating snapshots.

TECH STACK
----------
Frontend: Kotlin, Android SDK, Jetpack Compose, Material 3.
Backend: Python, FastAPI, Uvicorn, JSON REST endpoints.
Local database: SQLite. Production database: PostgreSQL via psycopg.
Assessments: question/answer JSON is compacted server-side before the OpenRouter
Chat Completions API call. MCQs are validated locally; the model grades subjective
answers and returns a validated JSON analysis. Mock tests are non-persistent.
Provider keys stay on the backend and are never shipped in the APK.
Hosting: Render free web service; Neon PostgreSQL is hosted separately.

DEPLOYMENT AND MOBILE APP
-------------------------
The root render.yaml defines the backend service with rootDir=backend and
automatic Blueprint sync/deploys on commits to master. The Android app is in
the same repository but Render does not build or deploy it. The API URL is the
default in new APK builds; the app also saves a per-device backend URL override.
Render's free service may spin down while idle, so its first request can be slow.

Build the installable debug APK from the repository root:
    ./gradlew assembleDebug

Output:
    AIClassroom_v1.0.apk

Install the APK on a phone, sign in using the class account usernames below,
and test connection to the Render API. The last observed Render health response
was status=ok with provider=openai and model=gpt-4.1-mini, before the OpenRouter
switch. Recheck provider/model and PostgreSQL health after deploying the update.

ACCOUNTS AND SECRETS
--------------------
The deterministic seed creates Class 9 sections A-D, 80 students per section,
20 teachers, 10 subjects, four tests per subject, metrics, synthetic analysis,
and historical rating snapshots. Seed accounts use DEMO_STUDENT_PASSWORD and
DEMO_TEACHER_PASSWORD; the production administrator uses ADMIN_USERNAME and
ADMIN_PASSWORD. Passwords are hosting/local secrets and must never appear in
this file, source code, APK, or public Git history.

backend/.env and render-secrets.txt are ignored by Git. Keep DATABASE_URL,
OPEN_ROUTER_API_KEY, account passwords, and ADMIN_PASSWORD in private local or
hosting settings only. OpenRouter is the configured analysis provider.

LOCAL BACKEND DEVELOPMENT
-------------------------
From backend/, create/activate a virtual environment, install requirements,
and keep local values in the ignored backend/.env. Then run:
    uvicorn main:app --host 0.0.0.0 --port 8000

Local development uses SQLite by default. Set DATABASE_URL to use PostgreSQL.
For LAN phone testing, enter the development machine's reachable address in the
app. Local HTTP is for development only; hosted phones should use the HTTPS
Render URL.
